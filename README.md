# 👋 Compañeros y compañeras

Para que podamos trabajar de forma organizada y que el proyecto quede lo mejor posible, os dejo algunas pautas que estaría bien que todos siguiéramos durante el desarrollo.

## 📐 Diagramas de clases
Es importante que, antes de implementar cualquier parte del proyecto, hagamos los diagramas de clases correspondientes. Así podremos tener claro cómo se relacionan las entidades y evitar problemas de diseño o conflictos entre nosotros.

## 📋 Organización en Trello
- Id actualizando las tarjetas según vayáis avanzando.
- Cuando empecéis una tarea, movedla a **En curso**.
- Cuando la terminéis, movedla a **En revisión** o **Hecho**, según corresponda.
- Intentad dejar una pequeña descripción de lo que habéis realizado.
- Si podéis, añadid capturas, imágenes o cualquier información que ayude a entender el trabajo realizado.

La idea es que Trello refleje lo que estamos haciendo y que todos podamos seguir el progreso del proyecto sin tener que preguntar constantemente.

## 💬 Comentarios en el código
Intentad añadir comentarios y documentación XML en las clases y propiedades para explicar brevemente qué representa cada una y cuál es su función. Esto nos ayudará a entender mejor el código de los demás.

## 📁 Organización de los modelos
Intentemos mantener los modelos agrupados por funcionalidades, evitando tener todas las clases mezcladas en una misma carpeta.

Por ejemplo:
- **Vehículos:** Vehículo, Marca, Modelo, Categoría, etc.
- **Reservas:** Reserva, LineaReserva, etc.
- **Pagos:** Pago y sus enumeraciones.
- **Trabajadores y clientes:** sus respectivos modelos.

Así tendremos todo un poquito más organizado y será más fácil encontrar cada cosa.

---

La idea es que todos sigamos más o menos estos criterios para evitar desorganización, duplicidad de trabajo y conflictos cuando integremos nuestras ramas.
